## My process

### Built with

- Vanilla Javascript, HTML5 & CSS
- Antigravity CLI

### What I learned

The main purpose of this small project was to use an Ai to build an application from end-to-end. The process was for the most part smooth. 
I asked the Ai for things and it delivered. There were some back and forth and sometimes I felt that it just didn't understand what I was trying to say
but after some very detailed instructions and clarifications it helped built exactly what I wanted. 

The best part. I learned about data attribute as I inspected the code that Antigravity CLI Ai created. Not only that, I also dove deep into JavaScript classes as I've never used them when I code as
most of the things I build, being a complete newb and all, are very simple. 


### Continued development

I'm going to continue to use Ai as a partner in creating apps. It was very convenient, fast and  helpful but I feel I'm going to be using it more as a teaching tool, 
a debugger, a function auto complete tool, than something that I would let create a full application. I found that it was much easier to get what I wanted if I broke things down
into bite size pieces.
